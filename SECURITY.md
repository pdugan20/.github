# Security policy

This policy applies to every pdugan20 repository that doesn't have its own
`SECURITY.md`. A repository's own policy replaces this one, usually to say what
counts as a security issue for that project.

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, pull requests,
or discussions.

Report them privately instead: open the repository's **Security** tab and
choose **Report a vulnerability**. That creates a private advisory that only you
and the maintainer can see.

Include the affected version or commit, steps to reproduce, and the impact you
expect. I'll acknowledge the report, work on a fix, and coordinate disclosure
with you.

## Supported versions

Security fixes go to the latest release. For repositories without releases,
fixes go to the default branch.
